# カートに入れる

## 仕様

- 本の詳細ページから、冊数を選んでカートに入れられる
- 在庫より多い冊数は入れられない
- 同じ本をもう一度入れると、冊数が増える
- ログインしていなくても使える。ログインすると、カートが引き継がれる

## 設計

- 在庫の確認は、カートに入れるときと注文するときの両方でやる
- ログインしていない人のカートは、Cookie の ID で持つ

## コード

- 追加の処理と在庫の確認: src/cart/add.ts
- ログイン時の引き継ぎ: src/cart/merge.ts
- 画面: src/pages/book.tsx

## データ

- carts
- cart_items
- books
