# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Tidyspec reads files and git history from a repository you point it at, and serves a preview on localhost. Reports about path traversal, reading files outside the repository, or the preview server being reachable from other machines are especially welcome.

There is no released version yet, so there is no supported-version table.
